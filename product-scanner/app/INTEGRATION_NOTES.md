# Подключение базы цен, геолокации и доставки

## Файл с предложениями

Приложение ожидает файл `public/data/product_offers.csv` в корне проекта. Его не было в присланном архиве `app`, поэтому существующую базу цен этот пакет не меняет.

Обязательные колонки CSV:

- `brand`
- `product_name`
- `current_price_rub`
- `regular_price_rub`
- `is_promo` (`true` / `false`)
- `store`
- `city`
- `store_address`
- `availability`

Необязательные колонки:

- `barcode` — предпочтительный способ точного сопоставления товара;
- `latitude`, `longitude` — координаты магазина в десятичных градусах (WGS84), необходимые для поиска поблизости;
- `delivery_service` — название сервиса доставки;
- `delivery_fee_rub` — стоимость доставки;
- `delivery_minimum_rub` — минимальная сумма заказа, если применимо.

Для корректного поиска рядом добавляй координаты к каждой записи магазина. Если координат нет, приложение не будет выдумывать расстояние: пользователь увидит сообщение, что поблизости нельзя проверить предложения.

## Источник и актуальность цен

Цена товара берётся из CSV. Сама по себе загрузка CSV не делает цену актуальной: данные должны поступать из собственного обновляемого источника или официальной интеграции магазина. Без API/договора/доступа к данным Купера и Самоката приложение не может достоверно получить их текущие цены, наличие и тарифы доставки.

В блоке доставки, если в CSV нет `delivery_service` и `delivery_fee_rub`, показываются **только демонстрационные значения** Купер — 100 ₽ и Самокат — 110 ₽ для демонстрации расчёта итоговой суммы. Это не реальные текущие тарифы сервисов. Чтобы показывать данные базы, добавь эти колонки в CSV и заполняй их подтверждёнными значениями.

## Данные о составе

Карточка продукта и сравнение второго продукта используют Open Food Facts по штрихкоду. Данные в каталоге пользовательские и могут быть неполными. Сравнение цен для второго товара работает только при наличии достаточно точного совпадения в CSV. Подсветка E-кодов — справочная эвристика, не медицинское заключение и не анализ концентрации добавок.


## Радиус поиска магазинов

В блоке предложений есть переключатель «10 км / 50 км / Все магазины». Для радиусов 10 и 50 км браузер должен разрешить геолокацию; расстояние считается по координатам WGS84 из `latitude` и `longitude`. «Все магазины» показывает все подходящие предложения из CSV без географической фильтрации.

Для генерации искусственных тестовых точек в пределах 12 км от центра Москвы запусти `python add_moscow_coordinates.py` из корня проекта. Координаты воспроизводимы: одинаковая комбинация города, магазина и адреса получает одну точку. Это фиктивные координаты для тестирования, а не реальные адреса филиалов.
